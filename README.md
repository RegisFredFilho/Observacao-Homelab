# Infra Observability Lab

Laboratório de observabilidade e monitoramento
de infraestrutura utilizando Proxmox VE,
Zabbix, Grafana, Python e GitHub Actions.

## Objetivos

- Monitoramento de recursos e disponibilidade
- Dashboards de infraestrutura
- Alertas e resposta a incidentes
- Automação com Python
- Testes automatizados
- Documentação técnica
